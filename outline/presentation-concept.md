# Presentation Concept

## Core Thesis

Gaming becomes art not only through image, sound, or story, but through designed interaction that creates meaning, emotion, and learning in the player.

## Planned Flow

1. Hook: introduce art and media through their unique expressive tools.
2. Compare manga, film, music, and games.
3. Present the controller as a communication tool for interactivity.
4. Define game design disciplines and immersion as a target.
5. Use the Dark Souls tutorial as the main walkthrough and analysis section.
6. Contrast positive design with manipulative design patterns such as FOMO.
7. Conclude with why game design can make games an art form.

## Opening Hook

- Manga example: page turn.
- Music example: classical piece, showing tempo and emotional control.
- Film example: still open; strongest candidates are camera perspective, montage, or a famous cut sequence.
- Games example: controller + button press -> system response -> feedback loop.

## Main Analysis Lenses

- Mechanics
- Player Guidance
- Level Design
- Feedback / Game Feel
- Difficulty / Challenge Design
- Reward / Motivation
- Sound Design
- World Building / Narrative Context

## Dark Souls Main Case Study

Potential walkthrough beats:

- opening cinematic as world building
- interactive tutorial prompts
- Oscar as diegetic guidance
- first Asylum Demon encounter
- respawn and retry structure
- Estus as resource teaching
- torch highlighting / environmental emphasis
- narrow corridor / bow / shield teaching moments
- rematch and earned mastery

## Critical Contrast Section

- Over-explained tutorials
- excessive UI guidance
- reduced consequence loops
- FOMO / dark patterns in service games

## Asset Plan

- Prefer recorded Dark Souls footage for reliability.
- Keep a live demo only as optional backup or for a short controlled segment.
- Capture short clips, not long continuous footage.
- Use zoom and highlight edits to direct attention to design elements.
