# Game Design Presentation

This area stores the presentation concept, structure, media plan, and future assets.

Current direction:

- Frame gaming as an artistic medium through interactivity.
- Use a Dark Souls tutorial walkthrough as the main case study.
- Contrast strong design choices with more guided AAA conventions and with manipulative dark pattern design such as FOMO.

Suggested future additions:

- `assets/` for captured footage, screenshots, controller photos, and exported slides.
- `outline/` for structure and speaking flow.
- `script/` for speaker notes.
