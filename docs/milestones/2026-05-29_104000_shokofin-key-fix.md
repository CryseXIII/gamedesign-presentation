# Milestone: Shokofin Key Fix

## Context
Jellyfin was still showing no Shoko-backed metadata because the Shokofin plugin configuration had an empty `ApiKey`.

## Decision
Create a dedicated Shoko API key for Shokofin, write it into the Jellyfin plugin configuration, and restart Jellyfin so the plugin loads the new credential.

## Rationale
Shokofin needs a valid Shoko API key to talk to the server. Shoko already had live AniDB settings and a working AVDump path, so the missing plugin key was the direct blocker on the Jellyfin side.

## Challenges
- The Jellyfin plugin config had to be edited in-place on CT212.
- Jellyfin needed a restart to load the updated plugin credential.

## Implementation Notes
- Minted a dedicated Shoko API key for `shokofin`.
- Updated `/var/lib/jellyfin/plugins/configurations/Shokofin.xml`.
- Restarted Jellyfin successfully.

## Follow-Up
- If Jellyfin still shows nothing after a metadata refresh, check the anime library mapping next.
- Avoid running a full Shoko import unless library-wide reprocessing is actually desired.
