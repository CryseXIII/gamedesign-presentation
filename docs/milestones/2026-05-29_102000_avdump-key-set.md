# Milestone: AVDump Key Set

## Context
The user provided the AniDB UDP API password (`GelbeGiraffe13`) after setting it in AniDB account settings.

## Decision
Update live Shoko settings so `AniDb.AVDumpKey` matches the user's AniDB UDP API password.

## Rationale
Shoko needs this value for AVDump-related AniDB communication. The setting can be updated live through the v3 settings API, so no restart was necessary.

## Challenges
- The settings endpoint required `api-version=3.0` and JSON Patch.
- The value had to be sourced from the user's supplied UDP API key, not inferred from the server.

## Implementation Notes
- Patched live Shoko settings on CT213.
- Verified the stored value via `GET /api/v3/Settings?api-version=3.0`.
- Left Jellyfin/Shokofin untouched.

## Follow-Up
- Use the installed `avdump3` wrapper on CT213 for any future AVDump runs.
- If the AniDB key changes again, patch the same Shoko setting with the new value.
